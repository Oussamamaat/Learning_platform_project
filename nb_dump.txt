# Darija Enterprise Tutor — LoRA Fine-Tune of Atlas-Chat-9B (Unsloth)

Trains one LoRA adapter on the **3,064-row** `v11_merged` dataset
and exports it for vLLM multi-LoRA (primary) plus a Q4_K_M GGUF for Ollama
(secondary). Read this cell before running anything.

## Run this with "Save & Run All (Commit)", NOT interactively

Same rule as the generation runs: an interactive session has a 60-minute idle
timeout that kills every process in the container. A committed run is
headless, has no idle timeout, and persists `/kaggle/working` as version

**Settings:** Accelerator: **GPU T4 x2** (or P100) · Internet: **On** ·
Persistence: Variables and Files.

**Dataset upload must contain:** `v11_merged/` (with `train.jsonl`

## The four decisions that determine whether this fine-tune is any good

Each was derived from the actual model config and the actual dataset, not
from a template. If you change one, read the reason first.

### 1. Atlas-Chat's chat template rejects the `system` role — we ship our own

`MBZUAI-Paris/Atlas-Chat-9B`'s `tokenizer_config.json` contains:

```jinja
{% if messages[0]['role'] == 'system' %}{{ raise_exception('System role not supported') }}{% endif %}
```

Every one of our 3,064 rows starts with a `system` message, so
`tokenizer.apply_chat_template(row["messages"])` raises on **100% of the
dataset**. Gemma-2 has no system turn at all.

`LOCKEDIN_PLAN.md` §6 called this out and marked it "Not yet implemented":
the system content must be **merged into the first user turn**, and the
*same* merge must happen at serving time or the model is fine-tuned on a
format production never sends.

This notebook resolves it by parity-by-construction rather than by
convention:

1. §4 installs a **custom `chat_template`** on the tokenizer that merges
   `system` into the first user turn with a blank-line separator.
2. It then **asserts** that the hand-written encoder used for training
   produces byte-identical output to that template. If they ever disagree,
   the run stops.
3. The patched tokenizer is saved **with the adapter**, so vLLM / HF / TGI
   reproduce the training format automatically with no extra code.
4. A matching Ollama `Modelfile` `TEMPLATE` is written next to the GGUF, so
   the Ollama path cannot drift either.

The rendered training format is exactly:

```
<bos><start_of_turn>user
{SYSTEM}

{USER_1}<end_of_turn>
<start_of_turn>model
{ASSISTANT_1}<end_of_turn>
<start_of_turn>user
{USER_2}<end_of_turn>
<start_of_turn>model
{ASSISTANT_2}<end_of_turn>
```

### 2. Assistant-only masking is mandatory here, not a nice-to-have

Measured on this dataset: the system prompt is **2,086 of the 2,456 median
characters** per row (85%), and there are only **99 distinct system prompts** across
3,064 rows -- more corpus-document contexts and component/domain
combinations than the prior export (which added five new components:
`structured_explanation`, `learner_adaptation`, `no_context_refusal`,
`general_knowledge_disclosed`, `injection_resistance`), but still ~31x
repetition per prompt.

Train on full sequences and roughly 85% of the gradient signal is 99 fixed
strings repeated ~31 times each — the model learns to recite its own system
prompt instead of to tutor. §6 masks every `user` span and every
`<start_of_turn>...` header to `-100`, keeps each assistant body **including
its `<end_of_turn>`**, then prints and asserts the result.

### 3. Single GPU, pinned before `import torch`

Unsloth OSS is single-GPU. Left unpinned on a 2×T4 box, HF `Trainer` sees two
devices and silently wraps the model in `nn.DataParallel`, which breaks
Unsloth's patched kernels and gradient checkpointing. Unsloth's own docs note
that on Kaggle's 2×T4, **1 T4 is faster than 2 anyway** because of that
overhead. §1 sets `CUDA_VISIBLE_DEVICES=0` before any CUDA import and asserts
exactly one visible device.

Nothing in §1's first cell may import torch — the torch reinstall in the next
cell only takes effect on first import.

### 4. The tuned model would not know how to stop

`generation_config.json` ships `eos_token_id: 1` (`<eos>`), but Gemma-2
conversations terminate with `<end_of_turn>` (id 107), which is what this
dataset trains the model to emit. Serve it unpatched and the model emits
`<end_of_turn>`, nothing stops it, and it continues by role-playing the
user's next turn.

§11 patches the exported `generation_config` to `eos_token_id: [1, 107]` and
writes `PARAMETER stop "<end_of_turn>"` into the Modelfile. It also drops
Atlas-Chat's `"repetition_penalty": "1.2"`, which is a **string** upstream and
makes some loaders throw.

## Hyperparameters, and why these

| Setting | Value | Reason |
|---|---|---|
| `r` | **16** | `LOCKEDIN_PLAN.md` §6 flags r=32 (≈108M trainable params) as oversized for this row count and recommends evaluating r=16. r=16 ≈ 54M params against ~2.4M trainable tokens — still heavily over-parameterised, so the real constraint is steps×lr, not capacity. |
| `lora_alpha` | **16** | Scaling 1.0, Unsloth's validated default for r=16, paired with lr 2e-4. |
| `lora_dropout` | **0** | Required by Unsloth's fast LoRA path. |
| target modules | all 7 linear | `q,k,v,o,gate,up,down`. No `embed_tokens`/`lm_head` — we are not teaching new tokens, and Gemma-2's 256k-row embedding would dominate the adapter. |
| `max_seq_length` | **4096** | Measured: p99 = 4,209 chars, max = 8,084 (both lower than the prior export's 4,547 / 10,833 -- the new components skew shorter). 4096 tokens clears p99 comfortably and stays inside Gemma-2's 8192 native window and 4096 sliding window, so no RoPE scaling. §5 reports real token lengths and **drops** (never truncates) anything longer — a truncated row teaches mid-sentence stops and loses its `<end_of_turn>`. |
| batch / accum | **1 × 16** | Effective batch 16. bs=1 means zero padding waste and no OOM from two long rows colliding in one batch; on a T4 the 4-bit model is dequant-bound, so bs=1 costs less throughput than an hour-3 OOM costs you. |
| epochs | **2** | ~346 optimizer steps on 2,757 rows. The adapter is saved **every epoch**, so if epoch 2 overfits, epoch 1 is still on disk. |
| lr / schedule | **2e-4**, cosine, 3% warmup | Standard for LoRA at this scale. |
| `optim` | `adamw_8bit` | Halves optimizer-state VRAM at no measurable quality cost. |
| precision | **fp16** on T4 | T4 (SM 7.5) has no bf16. Auto-detected; bf16 is used where supported. |
| `packing` | **off** (n/a) | Packing concatenates examples, corrupting per-example masking and letting one row's answer condition another's. We pre-tokenize, so it is structurally absent. |

**Trainer choice:** plain `transformers.Trainer` over a pre-tokenized dataset,
not `SFTTrainer`. Unsloth's speedups live in the patched *model*, not the
trainer, and once we pre-tokenize with explicit `labels` there is nothing left
for TRL to do except be a moving API surface (`tokenizer` →
`processing_class`, `max_seq_length` → `max_length`, `dataset_text_field`
relocating into `SFTConfig`). Argument names that *did* move are resolved by
signature introspection in §7, so this notebook survives version drift.

import json
from collections import Counter

def load_jsonl(path):
    rows = []
    with open(path, "r", encoding="utf-8") as fh:
        for lineno, line in enumerate(fh, 1):
            line = line.strip()
            if not line:
                continue
            try:
                rows.append(json.loads(line))
            except json.JSONDecodeError as e:
                raise SystemExit(f"{path}:{lineno} is not valid JSON: {e}")
    return rows

train_rows = load_jsonl(TRAIN_JSONL)
eval_rows = load_jsonl(EVAL_JSONL)
print(f"train.jsonl {len(train_rows):5d} rows")
print(f"eval.jsonl  {len(eval_rows):5d} rows")
print(f"total       {len(train_rows) + len(eval_rows):5d} rows")

CONTROL_TOKENS = ("<start_of_turn>", "<end_of_turn>", "<bos>", "<eos>", "<pad>")

def validate(rows, label):
    """Check every invariant the masking in Section 6 depends on."""
    problems = Counter()
    for r in rows:
        ms = r.get("messages") or []
        if not ms or ms[0]["role"] != "system":
            problems["no leading system message"] += 1
            continue
        if any(m["role"] == "system" for m in ms[1:]):
            problems["system message after position 0"] += 1
        body = ms[1:]
        expected = ["user" if i % 2 == 0 else "assistant" for i in range(len(body))]
        if [m["role"] for m in body] != expected:
            problems["roles do not alternate user/assistant"] += 1
        if not body or body[-1]["role"] != "assistant":
            problems["does not end on an assistant turn"] += 1
        for m in ms:
            if not m.get("content", "").strip():
                problems["empty message content"] += 1
            if any(t in m["content"] for t in CONTROL_TOKENS):
                problems["Gemma control token inside content"] += 1
    print(f"\n{label}: {len(rows)} rows, {sum(problems.values())} problems")
    for k, v in problems.items():
        print(f"  {k}: {v}")
    return problems

p1 = validate(train_rows, "train")
p2 = validate(eval_rows, "eval")
assert not (p1 + p2), (
    "Dataset violates a structural invariant the masking depends on (see "
    "above). Do not train on this; fix the export first."
)

print("\nby component:")
all_rows = train_rows + eval_rows
for comp, n in Counter(r["component"] for r in all_rows).most_common():

# Parrot filter -- standing safety net, not a fix for a currently-known
# defect. QUALITY_FLAGS.md section 7's "few-shot parroting" failure mode
# (assistant echoes a chunk of the user's turn verbatim before answering)
# hit 9 rows (0.34%) in the dataset this notebook was originally written
# against; v11_merged already measures at 2/3,064 (0.07%), well under the
# 5% kill line below. Kept as a regression guard, not an active cleanup.
# The threshold is deliberately conservative: 50 consecutive characters is
# far beyond coincidental overlap in Darija.
PARROT_CHARS = 50

def is_parrot(row):
    users = [m["content"].strip() for m in row["messages"] if m["role"] == "user"]
    answers = " ".join(m["content"] for m in row["messages"]
                       if m["role"] == "assistant")
    return any(u[:PARROT_CHARS] in answers for u in users if len(u) >= PARROT_CHARS)

_before = (len(train_rows), len(eval_rows))
parrot_rows = [r for r in train_rows + eval_rows if is_parrot(r)]
train_rows = [r for r in train_rows if not is_parrot(r)]
eval_rows = [r for r in eval_rows if not is_parrot(r)]
all_rows = train_rows + eval_rows

print(f"parroting rows dropped: {len(parrot_rows)} "
      f"({len(parrot_rows) / sum(_before):.2%})")
for comp, k in Counter(r["component"] for r in parrot_rows).most_common():
    print(f"  {comp:24s} {k}")
print(f"train {_before[0]} -> {len(train_rows)}   eval {_before[1]} -> {len(eval_rows)}")
assert len(parrot_rows) / sum(_before) < 0.05, (
    "More than 5% of rows are parroting the user. That is a generation-prompt "
    "defect, not something to filter away — fix it upstream and regenerate."
)

`MBZUAI-Paris/Atlas-Chat-9B` is not gated (Gemma licence, no access request),
so no `HF_TOKEN` is needed. No pre-quantised Unsloth build of it exists, so

## Section 4 — Install a system-aware chat template, and prove it matches

Atlas-Chat's stock template raises on `system`. This installs a replacement
that merges the system message into the first user turn, keeping everything
else byte-identical to Gemma-2's format (`| trim` on content, `<bos>` prefix,
`<end_of_turn>\n` terminators, `assistant` renamed to `model`).

The assertion at the bottom is the load-bearing line of the whole notebook: it
proves the encoder used for **training** and the template shipped to
**production** emit the same bytes. Edit one without the other and the run
stops here instead of six hours later.

===== CELL 14 [code] =====
# Merges `system` into the first user turn. Otherwise identical to Atlas-Chat's
# stock Gemma-2 template, alternation guard included. Raw strings keep the
# backslash-n as Jinja source (Jinja unescapes it), matching upstream's form.
# Content and terminator are emitted as separate {{ }} statements rather than
# `content | trim + '<end_of_turn>'` so filter-vs-plus precedence cannot bite.
SYSTEM_JOIN = "\n\n"

CHAT_TEMPLATE = (
    "{{ bos_token }}"
    "{%- if messages[0]['role'] == 'system' -%}"
    "{%- set system_message = messages[0]['content'] | trim -%}"
    "{%- set loop_messages = messages[1:] -%}"
    "{%- else -%}"
    "{%- set system_message = '' -%}"
    "{%- set loop_messages = messages -%}"
    "{%- endif -%}"
    "{%- for message in loop_messages -%}"
    "{%- if (message['role'] == 'user') != (loop.index0 % 2 == 0) -%}"
    "{{ raise_exception('Conversation roles must alternate user/assistant/user/assistant/...') }}"
    "{%- endif -%}"
    "{%- if message['role'] == 'assistant' -%}"
    "{%- set role = 'model' -%}"
    "{%- else -%}"
    "{%- set role = message['role'] -%}"
    "{%- endif -%}"
    r"{{ '<start_of_turn>' + role + '\n' }}"
    "{%- if loop.first and system_message -%}"
    r"{{ system_message + '\n\n' }}"
    "{%- endif -%}"
    "{{ message['content'] | trim }}"
    r"{{ '<end_of_turn>\n' }}"
    "{%- endfor -%}"
    "{%- if add_generation_prompt -%}"
    r"{{ '<start_of_turn>model\n' }}"
    "{%- endif -%}"
)

tokenizer.chat_template = CHAT_TEMPLATE

EOT_ID = tokenizer.convert_tokens_to_ids("<end_of_turn>")
BOS_ID = tokenizer.bos_token_id
assert EOT_ID is not None and EOT_ID != tokenizer.unk_token_id, \
    "<end_of_turn> is not a real token in this tokenizer"

def split_system(messages):
    """Return (system_text_or_None, remaining_messages)."""
    ms = list(messages)
    if ms and ms[0]["role"] == "system":
        return ms[0]["content"].strip(), ms[1:]
    return None, ms


def render(messages):
    """Render to training text. Deliberately WITHOUT <bos>: the tokenizer adds
    exactly one, and a literal <bos> here would produce the classic double-BOS
    that quietly degrades Gemma fine-tunes."""
    sys_txt, body = split_system(messages)
    out = []
    for i, m in enumerate(body):
        role = "model" if m["role"] == "assistant" else "user"
        content = m["content"].strip()
        if i == 0 and sys_txt:
            content = sys_txt + SYSTEM_JOIN + content
        out.append(f"<start_of_turn>{role}\n{content}<end_of_turn>\n")
    return "".join(out)

## Section 5 — Tokenise, measure real lengths, drop (never truncate) overlong rows

`MAX_SEQ_LENGTH` was chosen from character counts before a tokenizer was
available; this is where it gets checked against real token counts. Rows
longer than the limit are **dropped rather than truncated** — truncation cuts
an assistant answer mid-sentence and removes its `<end_of_turn>`, teaching the
model both to ramble and not to stop. Losing a handful of rows is far cheaper
than that.

===== CELL 17 [code] =====
def encode(messages):
    """Tokenise one row, masking everything except the assistant bodies.

    Each assistant's <end_of_turn> is deliberately INSIDE the unmasked span:
    that token is how the model learns to stop, and Atlas-Chat's
    generation_config does not list it as EOS (patched in Section 11)."""
    sys_txt, body = split_system(messages)
    ids = [BOS_ID]
    labels = [-100]
    for i, m in enumerate(body):
        role = "model" if m["role"] == "assistant" else "user"
        content = m["content"].strip()
        if i == 0 and sys_txt:
            content = sys_txt + SYSTEM_JOIN + content
        head = tokenizer(f"<start_of_turn>{role}\n",
                         add_special_tokens=False)["input_ids"]
        tail = tokenizer(f"{content}<end_of_turn>\n",
                         add_special_tokens=False)["input_ids"]
        ids += head + tail
        # The turn header is always context; the body is a target only on
        # model turns.
        labels += [-100] * len(head)
        labels += tail if role == "model" else [-100] * len(tail)
    assert len(ids) == len(labels)
    return ids, labels

import numpy as np

def build(rows, label):
    kept, dropped = [], []
    for i, r in enumerate(rows):
        ids, labels = encode(r["messages"])
        rec = {
            "input_ids": ids,
            "labels": labels,
            "attention_mask": [1] * len(ids),
            "component": r["component"],
            "src_idx": i,
            "n_tokens": len(ids),
            "n_target": sum(1 for x in labels if x != -100),
        }
        (dropped if len(ids) > MAX_SEQ_LENGTH else kept).append(rec)

    lens = np.array([r["n_tokens"] for r in kept + dropped])
    print(f"\n{label}: {len(rows)} rows")
    print(f"  tokens  min {lens.min():5d}  p50 {int(np.percentile(lens, 50)):5d}"
          f"  p90 {int(np.percentile(lens, 90)):5d}"
          f"  p99 {int(np.percentile(lens, 99)):5d}  max {lens.max():5d}")

          f"  min {tgt.min():.0%}  max {tgt.max():.0%}")

class TimeBudget(TrainerCallback):
    def __init__(self, hours):
        self.limit = hours * 3600
        self.t0 = time.time()

    def on_step_end(self, args, state, control, **kw):
        if time.time() - self.t0 > self.limit:
            print(f"\n[budget] {self.limit / 3600:.1f}h exhausted at step "
                  f"{state.global_step}/{total_steps} — stopping cleanly so the "
                  f"adapter still gets saved.")
            control.should_training_stop = True
        return control


class Heartbeat(TrainerCallback):
    """A committed run is watched through its log, so make the log useful."""

    def __init__(self):
        self.t0 = time.time()

    def on_log(self, args, state, control, logs=None, **kw):
        if not logs or "loss" not in logs:
            return
        el = time.time() - self.t0
        frac = max(state.global_step / total_steps, 1e-9)
        print(f"[step {state.global_step:4d}/{total_steps}] "
              f"loss {logs['loss']:.4f} lr {logs.get('learning_rate', 0):.2e} "
              f"| {el / 60:5.1f}m elapsed, ETA {(el / frac - el) / 60:5.1f}m "
              f"| VRAM {torch.cuda.max_memory_allocated() / 1e9:.1f}GB")

# GGUF is best-effort by design: merging to 16-bit needs ~18.5GB and llama.cpp
# has to be compiled. The adapter above is already safe on disk.
GGUF_BUILD = "/root/gguf_build"     # container disk, NOT the 20GB working quota
free_root = shutil.disk_usage("/")[2] / 1e9
free_work = shutil.disk_usage("/kaggle/working")[2] / 1e9
print(f"free: container {free_root:.1f} GB, working {free_work:.1f} GB "
      f"(need ~26 / ~7)")

if free_root < 26 or free_work < 7:
    print("SKIPPING GGUF export — not enough disk. Rebuild locally from the "
          "adapter zip; see FINETUNE_AND_DEPLOY.md.")
else:
    try:
        t_g = time.time()
        model.save_pretrained_gguf(GGUF_BUILD, tokenizer,
                                   quantization_method="q4_k_m")
        produced = sorted(Path(GGUF_BUILD).rglob("*.gguf"),
                          key=lambda p: p.stat().st_size, reverse=True)
        print(f"gguf build took {(time.time() - t_g) / 60:.1f} min; found "
              f"{[p.name for p in produced]}")
        if produced:
            dst = Path("/kaggle/working") / GGUF_NAME
            shutil.move(str(produced[0]), dst)
            print(f"GGUF -> {dst} ({dst.stat().st_size / 1e9:.2f} GB)")
            print("Left unzipped on purpose: a q4 GGUF does not compress, and "
                  "zipping it would need another ~6GB of the working quota.")
        shutil.rmtree(GGUF_BUILD, ignore_errors=True)
    except Exception as e:
        print(f"GGUF export FAILED ({type(e).__name__}: {e})")
        print("Newer Unsloth builds renamed the kwarg to quantization_type — "
              "if that is the error, retry with that name.")
        print("The adapter zip is unaffected; rebuild the GGUF locally.")
        shutil.rmtree(GGUF_BUILD, ignore_errors=True)
